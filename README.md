# MICO

A 3d printed, lightweight TV head, with periscopes for viewing, powered by HUB75 and Raspi!
The name MICO comes from Fa*MICO*m

Saw some projects like [2swap](https://github.com/autowattage/2swap) and [Minbitt's TV Head](https://www.youtube.com/watch?v=yEIA7uc1x5s) and was inspired to make my own... not knowing it would take three months of work and agony, and a missed convention

I learnt a LOT of Onshape (basically had to start from zero knowledge, you can see going down the line when i've learned a useful skill and left all the previous jank behind lol), plus I learnt how to use git, vscode, learnt how to solder a BMS and buck converter, like literally everything (can you tell this is my first project)

I designed this as a project for Hack Club's [Stardance!](https://stardance.hackclub.com/), as well as an aformentioned con that I couldn't make on time.... sadly...

## Features:
* Mounted periscope to view out of
* HUB75 screen
* 2p2s Battery (Or use a powerbank + USB C PD module)
* Macropad controlled animation switching (uses RPI 3B+ with USB Keyboard) 
* magnetic cat ears?
